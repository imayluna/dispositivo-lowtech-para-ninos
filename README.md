## Descripción

Proyecto Universitario de la Universidad de Chile, de parte del **Electivo Mención I y S: Dispositivos Low-Tech e Interfaces Interactivas**, este proyecto buscara la creación de un producto a base de la combinación del trabajo de Diseño conjunto con la electrónica Low-Tech, este repositorio servirá como una bitácora que contara con los detalles de proceso, código ocupado, proceso de prototipado y resultados finales.
